# Art of Palpation — Platform Source Export

This snapshot contains the current web app, Expo mobile app, API server, shared packages, mockup sandbox, project configuration, lockfile, and tracked assets.

Install dependencies with pnpm install from the project root. See replit.md and each package.json for project context and run commands.

Not included: environment secrets or credentials, installed dependencies, build outputs, Git history, internal agent notes, and live database or externally hosted account/storage data. Configure authentication and database services separately before running the platform elsewhere. This is a source export, not a backup of live service data.
